# 🌦️ Weather Update Web App  

A simple, responsive web application that provides real-time weather updates for any city using the OpenWeatherMap API. This project demonstrates the integration of a third-party API with frontend technologies to fetch and display weather information dynamically.

---

## 🚀 Features
- 🌍 Search for real-time weather updates for any location.
- 🌡️ Displays temperature in Celsius, weather descriptions, and a dynamic weather icon.
- 🎨 Clean and responsive UI built with HTML, CSS, and Bootstrap.
- ⚡ Fetch API for seamless data retrieval from the OpenWeatherMap API.

---

## 🛠️ Technologies Used
- **HTML**: Structure of the web app.
- **CSS**: Styling, including a custom background and layout.
- **Bootstrap**: For responsive design and components.
- **JavaScript**: Core functionality to fetch and display weather data.
- **OpenWeatherMap API**: For weather data integration.
